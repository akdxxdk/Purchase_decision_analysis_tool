# 购买决策分析工具 · 安卓版

一款跑在安卓手机上的**理性消费决策工具**：填写纠结购买的物品与自身条件后，App 直接
**联网搜索该商品真实信息**，再结合你的条件调用云端 AI 大模型进行多维度研判，
输出「可以购买 / 观望暂缓 / 不建议购买」的结构化分析报告。

本版与电脑 EXE 版功能完全一致，界面针对手机屏幕做了适配，无需电脑即可使用。

---

## 一、快速开始

### 1. 安装（只需 1 分钟）

1. 把 `购买决策分析工具-安卓版.apk` 发送到手机（微信文件传输助手 / QQ / 数据线均可）。
2. 在手机上点击该文件，按提示选择「允许安装未知来源应用」（各品牌手机设置位置不同，
   一般在安装弹窗或「设置 → 安全/更多设置」里），完成安装。
3. 要求 **Android 10（2019 年后的手机基本都支持）及以上**，无需 ROOT。

### 2. 配置 AI 模型（首次使用必做一次）

1. 打开 App，点右上角 **设置**。
2. 选择服务商（DeepSeek / 豆包·火山方舟 / 通义千问 / OpenAI / 自定义），自动填入接口地址与模型名。
3. 填入你自己的 **API Key**，点 **测试连接** 验证，再 **保存设置**。

| 服务商 | 获取 Key 的位置 |
|---|---|
| DeepSeek | platform.deepseek.com（充值后创建） |
| 豆包·火山方舟 | 火山引擎控制台 → 方舟 → 创建接入点（model 填接入点 ID 如 ep-xxxx） |
| 通义千问 | 阿里云百炼控制台（model 如 qwen-plus） |
| OpenAI | platform.openai.com |

> 任意 OpenAI 兼容的 `chat/completions` 接口均可（也支持本地部署的兼容网关）。
> **Key 只保存在你自己手机里**，App 不会上传到任何地方。

### 3. 开始研判

1. 选择商品品类（手机 / 电脑平板 / 线上课程 / 生活用品 / 家用电器 / 兴趣爱好 / 其他）。
2. 填写物品名称（如 `OPPO Find X10 Pro Max`）。
3. 填写自身条件（预算、现用设备、使用频次等，按品类动态变化）。
4. 点 **开始智能研判**：App 先联网搜索商品真实信息，再调用 AI 结合你的条件研判。
5. 查看**决策结论卡 + 联网搜索摘要 + 已读取页面（详情页价格/参数）+ AI 研判报告**，
   可一键复制或导出报告。

## 五、常见问题

- **安装时提示「未知来源」**：在系统设置中允许安装未知应用后再装一次。
- **安装提示「与已有应用签名不一致」**：说明已装过旧版本，先卸载旧版再安装（后续更新请用新版覆盖安装）。
- **「未配置 API Key」**：到设置里填写并保存。
- **「API Key 无效」**：Key 填错或已过期，检查后重填。
- **「无法连接模型服务」**：检查网络、接口地址是否正确（若自定义了 http 接口需保证手机可访问）。
- **搜索失败 / 无结果**：检查物品名称拼写，或换成更常见的叫法（品牌 + 型号）。
- **报告信息不完整**：公开网页尚未收录时，报告会如实标注「待官方核实」，不会编造数字，建议点报告中的官方链接核实。
- **点搜索结果没反应 / 跳转外部浏览器**：App 内链接默认用手机浏览器打开（设计如此）。

## 六、工程结构与重新构建

```
android-app/
├── AndroidManifest.xml            # 清单（包名 com.purchase.decisiontool，minSdk 29）
├── java/com/purchase/decisiontool # 原生代码
│   ├── MainActivity.java          # WebView 容器（含 JS 弹窗/外链处理）
│   ├── NativeBridge.java          # 前端 <-> 原生桥：config/search/analyze/test/导出/复制
│   ├── BingSearch.java            # 必应搜索解析（与 app.py 一致）
│   ├── PageExtractor.java         # 详情页正文关键信息提取（与 app.py 一致）
│   ├── LLMClient.java             # OpenAI 兼容大模型调用（与 app.py 一致）
│   └── BuildPrompt.java           # 研判提示词构造 + 结论解析（与 app.py 一致）
├── assets/web/                    # 前端（index.html/style.css + 移动适配 mobile.css + 桥接 bridge.js + app.js）
├── res/                           # 应用图标（5 种密度）
├── gen_icons.ps1                  # 图标生成脚本
├── build_apk.ps1                  # 一键构建脚本（自动下载 SDK 工具链）
├── debug.keystore                 # 调试签名密钥（勿删，用于覆盖安装）
└── test/TestMain.java             # 桌面冒烟测试（不打包进 APK）
```

重新构建（在 Windows 上，需联网首次自动下载工具链，约 3-5 分钟）：

```powershell
powershell -ExecutionPolicy Bypass -File "购买决策分析工具\android-app\build_apk.ps1"
```

产物输出到项目根目录：`购买决策分析工具-安卓版.apk`。
