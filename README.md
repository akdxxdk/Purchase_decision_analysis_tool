# 购买决策分析工具（EXE桌面版）软件需求说明书

## 1\. 项目概述

### 1\.1 项目名称

购买决策分析工具（桌面EXE版）

### 1\.2 项目背景

用户在购置贵重物品、数码设备、大件消费品、课程服务等高价商品时，极易出现**冲动消费、盲目跟风购买、购入后闲置浪费**的问题。

常规的心理自问、简单思考无法系统化判断消费合理性，因此需要一款轻量化、极简桌面工具，通过**左右对照利弊分析法**，强制理性思考，量化购买决策，杜绝无效消费。

### 1\.3 产品定位

一款**轻量化、无广告、单机本地运行**的Windows桌面EXE小工具。

主打「结构化利弊对照\+理性提问筛查\+决策结论输出」，专门解决个人冲动消费、纠结购物、不知道该不该买的痛点。

### 1\.4 核心理念

遵循用户原始思考逻辑：

买？不买？

对比：购买好处、经济能力、使用价值 VS 购买坏处、闲置风险、机会成本

通过标准化表单，把模糊的感觉，变成清晰、可落地的理性决策依据。

## 2\. 功能需求（核心开发功能）

### 2\.1 核心功能：双栏对照决策录入（核心特色）

软件主界面分为**左右两大固定板块**，用户手动填写内容，全程可视化对比。

#### 左栏【支持购买 · 正向维度】

固定5项理性提问，用户逐项填写：

1. 购买核心必要性：不买是否影响生活/工作/学习？现有设备/方案能否替代？

2. 经济承受能力：当前收入、存款是否可以轻松支付？是否占用应急资金？

3. 实际使用价值：买来能解决什么具体痛点？提升什么效率/体验？

4. 使用频次预估：每周/每月大概使用次数，是否高频刚需？

5. 长期收益：是否可以增值、省钱、省时、提升技能、创造收益？

#### 右栏【反对购买 · 风险维度】

固定5项理性提问，用户逐项填写：

1. 闲置风险：新鲜感过后，是否大概率吃灰、长期不用？

2. 经济成本：全款费用\+后续维护、耗材、升级隐性成本

3. 机会成本：这笔钱不买它，可以用来做哪些更重要的事？

4. 贬值损耗：产品是否高贬值、到手即折价、难二手转手？

5. 替代方案：是否有低价、二手、租借、免费替代方案？

### 2\.2 智能决策打分功能（新增优化功能）

每一项内容填写完成后，用户可手动给每一条打分（1\-10分）

- 正向得分越高 = 越值得买

- 风险得分越高 = 越不建议买

系统自动计算：

- 正向总分

- 风险总分

- 最终差值评分

### 2\.3 自动生成决策结论

根据分数差值，软件自动输出三种官方结论：

1. ✅ **理性建议：可以购买**（正向分显著高于风险分）

2. ⚖️ **理性建议：观望暂缓**（分数接近、利弊持平、非刚需）

3. ❌ **理性建议：不建议购买**（闲置风险、机会成本过高）

### 2\.4 记录保存功能

1. 本地自动保存每一次购物决策记录

2. 可查看历史决策列表（标注：物品名称、决策结果、日期）

3. 支持单条记录删除、清空全部记录

### 2\.5 报告导出功能

支持一键导出 **TXT决策报告**，内容包含：

- 物品名称

- 全部利弊对照内容

- 评分数据

- 系统最终决策结论

方便用户留存复盘。

### 2\.6 快速极简模式

针对小额纠结消费，开启极简模式：

减少提问条目，快速3问判断：刚需？能用替代？会不会闲置？

适合日常快速决策。
